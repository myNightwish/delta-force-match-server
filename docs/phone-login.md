# 可选手机号登录

匿名用户仍可发布招募、匹配、确认和聊天，手机号不作为参与门槛
基础信息旁提供手机号验证码登录入口，当前没有短信服务商配置时显示暂未开放，可以继续匿名使用

## 开启真实短信

当前适配器为 Twilio Verify，接口参考 https://www.twilio.com/docs/verify/api
在后端 Render Environment 配置以下值，不要放进前端或提交 Git

- PHONE_AUTH_ENABLED=true
- PHONE_AUTH_PROVIDER=twilio_verify
- PHONE_AUTH_SECRET：至少 32 字符的随机服务端密钥，用于手机号 HMAC，设定后应保持稳定
- TWILIO_ACCOUNT_SID
- TWILIO_AUTH_TOKEN
- TWILIO_VERIFY_SERVICE_SID

默认关闭，不依赖旧版 SMS_DEV_MODE / DEV_SMS_CODE，不返回固定码，不把服务商错误当成登录成功
真实发送、验证码送达和目标国家可用性须在配置服务商账号后验证，本次没有发送短信

## 会话和个人资料

- 验证后签发 30 天设备会话，数据库只保存会话摘要，退出只撤销当前设备
- 手机号只保存服务端 HMAC 和脱敏展示，不公开完整号码；密钥必须保持稳定
- 首次登录沿用本设备匿名身份，已有手机号账号在其他设备验证后恢复其身份和常用资料
- 不能从进行中匿名队伍静默切换到另一个账号，需先结束当前组局
- 个人资料同步昵称、游戏端、区服、语言、语音、时段、自身装备、打法与实力输入
- 本局目的、地图和队友要求继续使用本地草稿，不因登录静默修改已发布招募
- 登录入口所在的第四步即使未显示，也会在表单初始化时恢复已登录账号的常用资料
- 过期会话回到匿名身份，本地草稿仍保留

## 验证码约束

- 国际 E.164 号码格式，发送间隔 60 秒，手机号与匿名身份各限每小时 5 次，客户端 IP 限每小时 20 次
- 验证挑战绑定发起设备身份和号码，10 分钟有效，最多尝试 5 次，用后失效
- 服务商校验必须批准，不允许客户端自行判定验证码有效
- 生产部署应正确设置可信代理，确保服务端拿到真实客户端 IP，并开启服务商的防滥用保护
- 这些限制不代表完全防滥用；付费短信正式开放前还需要服务商侧预算与发送地区限制

浏览器测试只验证未配置时的关闭状态与匿名发布
验证码、会话、跨设备恢复和资料同步由注入模拟服务的自动测试验证，不存在运行时测试码开关
