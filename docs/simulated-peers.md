# 一人测试：模拟队友

## 使用

沿用页面底部的口令保护“测试入口”和 `PILOT_TEST_ACCESS_CODE`，无需新服务或新环境变量。

1. 解锁入口，默认选择“示例条件”，无需先填表；也可以选择“当前条件”，使用当前表单或已发布的招募条件，不完整时提示补全
2. 选择队友响应：自动确认、自动拒绝、超时不响应
3. 点击“生成 8 位模拟队友”，创建临时测试身份，自动发布自己的测试招募和 8 位模拟队友，不需要分别导入或发布
4. 点击“进入招募大厅”，选择兼容的队友申请；你只确认自己的约定，模拟队友自动完成另一方操作
5. 双方确认后，模拟队友会发送一条明确标记的测试消息，不自动代填人类反馈
6. “清理本轮测试”停止模拟队友、取消本轮未完成招募/队伍；若本页保留了原身份信息，会自动回到原身份和草稿

示例模式固定两位兼容队友，另外六位覆盖目标、战场、实力、反向打法、装备（无法构造装备冲突时使用语音差异）与区服。当前条件模式动态构造有效数据，再经过真实规则检查。测试面板展示预期与实际条件判断，队伍是否已保留单独展示。

## 隔离与生命周期

- 运行轮次保存到 `pilot_sim_runs`，成员绑定服务端的 `pool_id`，客户端不能提交或篡改所属池
- 大厅、推荐、自动匹配、直接邀请和“换一批”均检查候选池；真人和其他测试轮次不能互相发现或组队
- 模拟队友之间不能互相组队，只与本轮操作者组队
- 已存在真实进行中的招募时拒绝切换到模拟身份，以免中断真实组队
- 模拟队友由 FastAPI 生命周期中的后台循环每两秒处理一次，使用正常的发布、匹配、确认、拒绝、聊天服务
- 不直接把队伍改为成功，不延长正式的 120 秒确认期限，不伪造局后反馈
- 每轮持续 15 分钟，服务重启后未过期轮次会继续执行，到期自动取消，配置被关闭也会停止
- 重新生成前停止旧轮次，最多同时运行 5 轮，并有地址/身份频率限制；继续采用单实例、单 worker
- 清理采用取消和停止，不永久删除队伍、消息或调试记录，不触碰真人或其他测试轮次
- 模拟玩家仍标为 is_demo，不计入真实匹配效果统计；这只能检验功能，不是对真人体验或容量的验证

返回原身份的凭证与草稿仅保存在本浏览器当前标签的 sessionStorage/内存中，口令不保存。刷新后仍需重新解锁，可查询当前未过期轮次；浏览器禁用存储时只能保留当前页面内存，关闭页面可能失去原匿名身份的返回信息。

高级 JSON 导入保留在折叠区，主要用于额外边界数据，不需要作为日常测试入口。旧高级 JSON 独立身份导入不自动建立上述模拟轮次。

## 草稿保存诊断

- 区分数据归一化异常与存储写入异常，空间不足与浏览器限制有不同文案
- 不再把所有错误归因于存储权限；显示小型提示与重试入口，不阻止当前填写
- 自动保存改为 Vue 更新后批量处理，减少整份 JSON 导入期间的重复写入
- 开发控制台输出去重的 `[draft-save]` 阶段、异常名称和原因，不打印完整表单或凭证
- 身份凭证无法持久化时保留本页内存，避免存储异常打断当前操作

## 验证

后端：`.venv/bin/python -m unittest discover -s tests -q`
前端：`node --test tests/*.test.mjs`、`npm run build:h5`

前后端一起部署，数据库自动补测试池字段和模拟轮次表。无需部署 Redis、任务队列或独立 worker。
