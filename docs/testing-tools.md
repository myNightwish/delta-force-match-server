# 口令保护的匹配测试工具

当前默认入口已升级为 [一人模拟队友测试](simulated-peers.md)，下文 JSON 导入位于折叠的高级设置中

在后端设置 `PILOT_TEST_ACCESS_CODE`（至少 12 字符），重启或重新部署服务。留空时所有测试工具接口关闭，口令不能配置为前端 VITE 变量，不能提交到 Git。

页面最底部有“测试入口”，输入口令后才从服务端读取场景和显示 JSON 编辑区。授权 30 分钟有效，与当前身份绑定；授权令牌只保存在当前页面内存中，刷新需重新解锁。错误口令按地址及身份限流。

1. 选择场景和玩家 A / B，或读取本地单人 JSON 文件，也可直接粘贴 JSON
2. “导入当前玩家”只替换当前浏览器的表单草稿，不自动发布，不创建另一位玩家；已有进行中的招募会被拦截，手机号账号请使用新建测试玩家
3. “新建测试玩家并导入”创建独立测试身份并填入表单；当前有真实进行中的招募时不能切走，以免丢失联系
4. 导入后按原流程预览并发布，可在普通和无痕窗口分别操作 A、B
5. 也可在同一页面的“已导入的测试玩家”列表切换，每个身份分别保留服务端招募状态；列表仅在当前页面内存保存，刷新后不保留切换列表
6. 同页面切换会使旧身份停止心跳，其招募在约 75 秒后隐藏；需要双方持续在线、确认和聊天时优先使用两个浏览器窗口
7. “锁定入口”撤销当前身份所有测试授权，清除本页解锁内容；不删除队伍和聊天，也不会把测试身份转为真人

JSON 必须是一位玩家的 v4 招募对象，文件与后端接受的 JSON 内容上限 16 KB，仍经过正式表单模型验证。不会运行脚本或直接创建队伍，匹配逻辑与正式用户相同。

导入身份写入服务端测试标记，此后发布的招募强制使用“【测试】”昵称并标记 is_demo，即使刷新或修改表单也不计入真实效果统计。普通接口不能通过 JSON 的 is_demo 字段伪造该标记。测试玩家仍可能出现在大厅，或与条件相符的真人组局，测试时建议使用本地环境；标记不等同于测试池隔离。

内置 10 组场景位于 `app/testing/scenarios.json`，对应 20 份独立玩家 JSON 已另行提供。场景覆盖双向兼容、实力、反向打法、目标、地图难度、共同任务、装备、跑刀、公开与私密自动匹配。

前后端一起部署。Render 服务端 Environment 增加 `PILOT_TEST_ACCESS_CODE`，除此以外无需新增服务。不要上传本机 .env，线上口令由你在 Render 设置。
